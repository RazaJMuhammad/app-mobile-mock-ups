# Warren Kuhn — Padel & Fitness (client mockups)

Interactive iPhone-first prototype of the client coaching app. Dark mode is the default.

```bash
npm install
npm run dev
```

Open the local Vite URL, then:

- **Client** — click through the phone like a user
- **Gallery** — every spec screen + component library
- **Admin** — simple coach desk (photos, messages, clients)
- Header controls: First launch / no program / active client, iOS ↔ Android, Dark ↔ Light

Demo purchase path: set **First launch** → Sign up → onboarding → pick **6-Week Padel Conditioning** → Buy Now → App Store sheet → Start Program.
